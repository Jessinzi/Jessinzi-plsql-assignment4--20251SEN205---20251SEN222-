## 1. Introduction

This project focuses on developing a Hospital Records Management System using Oracle SQL and PL/SQL. It demonstrates how database tables and PL/SQL programming concepts can be used to manage hospital information, including departments, doctors, patients, appointments, medications, and prescriptions.

### 2. Database Tables

The system contains six tables:

1. DEPARTMENTS
    
2. DOCTORS
    
3. PATIENTS
    
4. APPOINTMENTS
    
5. MEDICATIONS
    
6. PRESCRIPTIONS
    

### 3. PL/SQL Concepts

The project demonstrates:

- Records (`%ROWTYPE` and user-defined records).
    
- Collections.
    
- Implicit and explicit cursors.
    
- Bulk processing (`BULK COLLECT` and `FORALL`).
    
- Stored procedures.
    
- Stored functions.
    
- Exception handling.
    

### 4. Technologies Used

- Oracle Database
    
- Oracle SQL and PL/SQL
    
- Deep seek as the AI assistant
